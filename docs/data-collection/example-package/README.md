# 示例数据包：重庆城市生命线

这是给业务人员参考的最小完整示例包。CSV 文件可以直接用 Excel 打开，编码请选择 UTF-8。

```text
example-package/
├── 00_提交说明.md
├── 01_来源登记.csv
├── 02_事件线索.csv
├── 03_组织职责.csv
├── 04_我方能力.csv
├── 05_历史案例.csv
└── 06_专家评测样本.csv
```

填写时先保存原文材料，再填写来源登记；其他表中的“来源编号”必须能在 `01_来源登记.csv` 找到。

这只是格式示例，内容中的单位、链接和案例需要在正式提交前由业务人员核验，不能直接当作生产数据导入。
